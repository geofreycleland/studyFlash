# AWS DEA-C01 Mock Exam

A mobile-friendly, static mock exam for **AWS Certified Data Engineer – Associate (DEA-C01)**.

## Features
- 65 original questions
- 130-minute timer
- Single-answer and multiple-response questions
- Flag questions for review
- Saves progress in the browser with `localStorage`
- Score and domain breakdown
- Full answer explanations
- Responsive/mobile-first layout
- No backend or dependencies

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Commit the file.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then save.
7. Open the GitHub Pages URL on your phone.

## Notes
This is an independent study tool. Questions are original and are not copied from AWS certification exams or exam dumps.

The question distribution is approximately aligned with the current DEA-C01 content-domain weighting:
- Data Ingestion and Transformation: 34%
- Data Store Management: 26%
- Data Operations and Support: 22%
- Data Security and Governance: 18%

AWS exam guides can change, so compare this practice tool against the latest official DEA-C01 exam guide before your exam.
